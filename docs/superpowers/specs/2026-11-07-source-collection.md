# Code Atlas 源码收藏

用户选择：公开仓库 HuWillis/code-atlas，采用源码副本而非 Fork 或子模块。后续用户给出 GitHub 链接，收录实际源码并自动跟随上游默认分支。

范围：sources.json 管理收录清单；repos/作者/仓库 保存快照；CATALOG.md 列出来源、用途、版本；notes/ 保存个人学习笔记。脚本不执行上游代码，保留许可证及版权文件。每天北京时间 09:23 由 Actions 检查，支持手动触发；定时任务可能延迟或被 GitHub 停用，README 说明恢复方法。

本次没有指定任何待收录项目，清单保持为空，不上传演示项目。公开收录仅允许公开上游；收录前人工确认许可证。Git 历史、Release 附件、LFS 实体与子模块递归内容不属于普通源码快照，遇到后两者明确失败，之后逐项目处理。单文件超过 90 MiB 时拒绝导入，避免不可推送的提交。

同步规则：先获取全部发生变更的项目快照，任何一个准备失败则不覆盖现有快照；相同版本不产生提交；更新包含上游删除的文件。仅替换清单对应的受管理目录，notes/ 不受影响。源码快照通过 git archive 提取，遵循上游 export-ignore；记录实际提交号。取消收录条目不会自动删除已有副本。
